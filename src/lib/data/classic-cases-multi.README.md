# 多爻同動案例（尚未使用）

43 則出自《易隱》《易冒》《易林補遺》《卜筮全書》的實占案例，格式與
`classic-cases.json` 相同，唯 `dongYao` 是陣列（如 `[2, 5]`）。

**本引擎目前是單動爻模型，無法使用這批資料**，暫存於此是為了在評估
「要不要擴充引擎支援多爻同動」時有實際數據可依據：

- 動爻數分布：兩爻 35 則、三爻 4 則、四爻 1 則、五爻 3 則。
  **若只擴充到支援兩爻同動，即可涵蓋八成。**
- 在《易隱》的合格樣本中，多動爻佔 42%（10/24）——這是被單動爻模型
  擋在門外的資料量級。
- **但擴充不只是「允許多個 dongYao 輸入」。** 古人斷多動爻卦時明顯是先定用神、
  再看動爻之間的作用順序（如「兄生子而子剋官」「兄乃貪生忘剋」），需要實作
  貪生忘剋與連續相生鏈的邏輯，不是把每個動爻獨立處理再加總。
  動工前應先確認這部分的成本。
- 附帶發現：《易冒》獨發章有三則「五爻同動」的教學例，古人是**取唯一的靜爻**
  來定應期（「一爻之靜，驗於相值，亦驗相沖」），這套規則與現行按動爻取用的
  邏輯是正交的。

採集方式與驗證同 `classic-cases.json`，動爻皆由本卦變卦爻象逐位比對推得
並經獨立重算複核（90/90 零誤差）。
